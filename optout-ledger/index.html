What you get

  • A spreadsheet and a data file with one row per request and per thing to remove: whole account or one repository, owner, repository, date filed, current state, link to the public issue and a fingerprint of the request text.
  • A filter script that reads your local copy (Parquet if you have pyarrow, or JSONL), drops the matching repositories, writes a filtered copy and a removal report with counts per request. It never changes your original files.
  • A list of requests we could not read, so nothing is hidden. In this edition that is 129 of 8,259.

Why not just read the issues yourself

The requests are free-text issues in several formats: whole accounts, repository lists, links, odd spacing. Turning thousands of them into a clean list takes hours each month, and a later edit can overwrite the earlier text. We keep a dated capture, so edits are recorded from the day we started capturing.

What this is not

It does not say any request is valid, that a licence is revoked, or that a model forgot anything. It is not legal advice. It covers requests filed in that one repository only, and it reads each issue’s comments only to catch the person who filed it cancelling; none was found as of 2026-10-01.
