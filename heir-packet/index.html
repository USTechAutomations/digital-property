From an export to a useful family list

  • packet.html: a printable list grouped into email, banking and money, phone, shopping, social, work and other. Each account has its website, username or email, and a blank line for “where the password is kept”.
  • accounts.csv: the same account details for a spreadsheet, with secret columns removed.
  • UNKNOWN.csv: fixed reasons for skipped rows, missing usernames and provider guidance that could not be confirmed. It never copies rejected cell contents.
  • Emergency-access guidance and official provider links are included where confirmed. A family member still needs the provider’s permission and process; the list cannot unlock an account.

Privacy has limits you should know

The importer reads the file in small byte chunks. It never decodes discarded secret cells or copies them to the preview, files or logs. Raw bytes briefly pass through memory during parsing; browser and operating-system memory cannot be guaranteed securely erased.

A password put in an account-name or username column can evade column filtering. Check the result privately before sharing. Even without passwords, this list contains personal account information. Keep it and the printout private.

Use a trusted personal computer. Keep the export away from shared computers, email and cloud-synced folders. On Windows, select it in File Explorer and press Shift+Delete. On Mac, move it to Trash and empty Trash. Remove any extracted Dashlane files and the original ZIP too. Deletion does not guarantee erasure from backups or SSDs.

What it cannot do

It cannot grant access, recover passwords or replace your password manager’s emergency plan. Apple Legacy Contact does not hand over Keychain passwords or passkeys. No legal advice is provided.

Use UTF-8 comma-separated CSV with a header. JSON, 1PUX, encrypted files and ZIP input are not supported. The limits are 50 MiB, 50,000 rows, 256 columns and 4,096 bytes per kept cell. Only the first 500 accounts have editable group previews. Website paths, queries and fragments are removed; only the first listed website is used. Groups need your review. Provider policies can change; unconfirmed guidance is marked UNKNOWN.

Is there a free way?

Yes. Write an account list in a document, or carefully remove secret columns from a CSV using an offline spreadsheet. Bitwarden and LastPass offer their own emergency-access arrangements on eligible plans; 1Password has its separate Emergency Kit. Those access arrangements are useful whether or not you buy this.

Heir Packet saves the work of copying account names, grouping them and formatting the printout. It fills the list from an export instead of asking you to fill in a blank planner. Read the free guide before exporting anything.
