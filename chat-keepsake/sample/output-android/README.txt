Chat Keepsake — Our family
Open index.html in a browser. Keep this whole folder together.
Date order inferred as MDY by checking valid calendar dates across the whole file. Review if exports were combined.
Message order is preserved from the export. Times are local as exported; no time zone was supplied. Two-digit years mean 2000–2099. The first valid message or known English notice selects one timestamp layout for this file. Only matching valid timestamps with a sender followed by colon-space, or a known English notice, start another message. Other lines stay verbatim in the preceding message. Unknown notice languages stay as text; combined exports should be built separately. A pasted line identical to a real header cannot be distinguished from a message. Sender names are split at the first colon followed by a space.
Check UNKNOWN.csv before sharing. Original input files are never changed.
Photos and audio only exist if WhatsApp included them. Some codecs need a separate player.
Print / Save as PDF includes all messages; sound and video stay in this folder, not the PDF.
CSV cells starting with formula characters are prefixed with an apostrophe for spreadsheet safety.
This book is not encrypted. Share only with people you choose.
