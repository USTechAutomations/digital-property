A free creator checklist

Send previews. Keep originals private.

You can prepare a safe client handoff with an image editor, a spreadsheet and separate folders. Start by separating what a client may view from what you intend to deliver.

Keep three copies separate

Keep your source images in a private folder. Make smaller preview copies in a second folder, add the client’s name and order id visibly, and inspect each preview. Put the selected originals for a paid order in a third folder. A watermark is a label, not a guarantee against copying or removal.

For a free manual option, GIMP lets you add a text layer and export a separate image. Its official Text tool guide and Export As guide explain the steps. Preserve your source file and export the preview under a new name.

Write down the exact order

A useful sheet has order_id, client_name, image_filenames, paid, licence_note. Give every order a unique id. In Preview Batcher, separate multiple filenames with |, such as portrait.jpg|detail.png; names containing | are outside this sheet format. Prefer exact relative paths when two folders contain the same basename. Match spelling and case.

Save the sheet as UTF-8 CSV. Quoted CSV fields can contain commas and line breaks; double an embedded quotation mark. The RFC 4180 CSV format reference describes these rules. A spreadsheet’s export function handles quoting for you. Check the exported sheet rather than editing commas by hand.

Decide what paid means before exporting

Check your own payment records and enter yes only for an order you intend to release. No, a blank cell or an uncertain value must not release clean originals. Preview Batcher reads that flag but never checks your bank or payment provider. Correct the sheet and rebuild if the flag is wrong.

Write the licence note you intend to provide. This guide does not tell you what rights you own or what a licence must contain.

Check the final handoff

Count the selected originals, record their source names, and add a delivery note with the date and your licence note. A SHA-256 fingerprint helps detect whether the bytes differ; it does not prove who owns an image. The browser’s official digest documentation describes SHA-256 support. Clients can compare the manifest with a local SHA-256 checker.

Open the finished overview and check its skipped-file report. Inspect the visible watermark and all delivered names. Send only that client’s previews or final folder. The complete batch reveals other clients’ details; do not share it.

Folder or ZIP?

Direct folder saving depends on browser support and permission. The directory-picker documentation describes that limited availability. If a folder cannot be saved, download a ZIP, extract it, then open index.html. Use a new empty destination so existing work is not overwritten.
